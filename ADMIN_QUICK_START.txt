🐛 IF YOU GET STUCK
================================================================================

Problem: "Login not working"
Solution: Make sure dev server is running
          Run: php artisan serve --port=8000

Problem: "Admin page shows error"
Solution: This is the Blade rendering issue (homepage only)
          Admin panel should still be accessible
          Try: Clear cache with php artisan view:clear

Problem: "Article not saving"
Solution: Make sure all required fields are filled
          Check that you clicked "Save" button
          Wait 2 seconds for save to complete

Problem: "Cannot see new articles"
Solution: Article saved as draft or scheduled
          Check Status field
          Change to Published if needed
